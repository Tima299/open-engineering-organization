# Getting help

OEO is maintained in the open on a best-effort basis by a single maintainer. There is no paid support
and no response-time guarantee.

| You want to... | Go here |
|---|---|
| Ask how to use OEO | [GitHub Discussions](https://github.com/Tima299/open-engineering-organization/discussions) if enabled, otherwise open an issue labeled `question` |
| Report a bug | [Bug report](https://github.com/Tima299/open-engineering-organization/issues/new?template=bug_report.yml) |
| Suggest a feature | [Feature request](https://github.com/Tima299/open-engineering-organization/issues/new?template=feature_request.yml) |
| Propose a new role | [Role proposal](https://github.com/Tima299/open-engineering-organization/issues/new?template=role_proposal.yml) |
| Report a vulnerability | [SECURITY.md](SECURITY.md) (never in a public issue) |
| Report a conduct problem | [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) |
| Contribute a fix | [CONTRIBUTING.md](CONTRIBUTING.md) |

## Before you ask
1. Read the [README](README.md) and [docs/roles.md](docs/roles.md).
2. Search existing issues and discussions.
3. For a bug, check you are on the latest release and collect your OEO version, Claude Code version,
   OS, and the output of `python3 scripts/oeo.py route ...` for the request in question.
4. Remove secrets, tokens and private code from anything you paste.

## Good questions
State what you tried, what you expected, and what happened. A short reproduction beats a long
description. Questions answered in public help the next person, so prefer a public thread over
a private message.
